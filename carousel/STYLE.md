# Стиль каруселей — Александр Бондарь · Кинезиолог

Фирменный визуальный стиль для Instagram-каруселей. Используй этот гайд +
`carousel.html` как шаблон и `render.js` для рендера в готовые картинки.

## Формат
- Размер слайда: **1080×1350** (4:5, вертикаль для ленты/Reels-промо).
- Рендер: `node render.js` → `slide_1.png … slide_6.png` (2160×2700, ×2 для чёткости).
- Браузер: Chromium из `/opt/pw-browsers` через `playwright-core` (см. render.js).

## Палитра
- Фон: `#0c0c0c` / `#0d0d0d` (почти чёрный).
- Акцент: жёлтый `#FFD400`.
- Текст: белый `#fff`, второстепенный — `rgba(255,255,255,.5–.9)`.
- Чёрный текст только на жёлтых плашках.

## Шрифты
- Заголовки: **Oswald** (condensed, 600–700), UPPERCASE, межбукв. −1px.
- Текст/абзацы: **Roboto** (300 для body, 700 для выделений).
- Google Fonts через @import; фолбэк — Arial Narrow / Impact / sans-serif.

## Постоянные элементы

- Внизу справа номер слайда: `01…06`.

## Структура карусели (6 слайдов) — проверенный сценарий
1. **HOOK** — самый сильный результат до/после на весь кадр + жёлтая плашка-цифра
   (напр. «−17 см за 13 дней без диет и тренировок») + «Листай →».
2. **ПРОБЛЕМА** — фото на весь кадр, заголовок белый+жёлтый, плашка-цифра, абзац снизу.
3. **ПРИЧИНЫ** (сплит) — текст сверху (нумерованный список 1–5, цифры жёлтые),
   фото снизу в чёрной зоне (object-fit: contain) + жёлтый ярлык-результат.
4. **ПОЧЕМУ НЕ ПОЛУЧАЕТСЯ** (сплит) — список с жёлтыми «✕», блок «Правило» с жёлтой
   левой границей; фото снизу + ярлык-результат.
5. **ОТЗЫВ / СОЦ.ДОКАЗАТЕЛЬСТВО** — скрин переписки клиента по центру на тёмном фоне,
   жёлтый заголовок-цифра сверху, подпись снизу.
6. **CTA** — скрин-доказательство сверху + крупный анонс («Через 2 дня выйдет Reels»),
   жёлтая кнопка-призыв («Напиши в личку: ОТЕКИ»), контакты.

## Приёмы, которые заходят
- На каждом фото — жёлтая плашка с конкретной цифрой результата (−см, −кг, дни).
- «До/После» подписываем только когда ориентация однозначна (или фото уже подписано).
  Если пара верх/низ — НЕ вешать метки лево/право.
- Цифры — главный смысловой акцент: крупный Oswald 700 на жёлтом.
- Тон текста: простой, без сложных терминов, «ты»-обращение.
