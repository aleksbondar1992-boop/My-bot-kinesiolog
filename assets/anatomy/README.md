# Параллельные линии тела (вид со спины)

Три схемы горизонтальных линий-уровней. Набор линий один и тот же,
различается нумерация — то есть последовательность работы.

| Файл | Схема |
|---|---|
| `body-lines-1-base.svg` | Базовая последовательность: глаза → челюсть → шея → апертура → диафрагма → таз → колени → стопы |
| `body-lines-2-alt-order.svg` | Другой порядок: за каждой опорной линией сразу её вспомогательная (апертура→шея, таз→диафрагма, стопы→колени) |
| `body-lines-3-neck-mobilization.svg` | Протокол мобилизации шеи: + линия грудины Th2–Th3, шея выделена как цель |

Оформление линий:

* **жирные красные — опорные:** глаза, челюсть, апертура грудной клетки, таз, стопы;
* тонкие синие пунктирные — вспомогательные: шея, диафрагма, колени;
* бирюзовые (только схема 3) — рабочие: грудобрюшная диафрагма и грудина Th2–Th3;
* фиолетовая (только схема 3) — цель: линия шеи.

Рядом с каждым `.svg` лежит `.png` того же размера (1000×1460).

## Перегенерация

```bash
pip install fonttools cairosvg      # cairosvg нужен только для PNG
python3 tools/generate_body_lines.py
```

Уровни линий, подписи и цвета задаются словарями `Y`, `META` и константами
палитры в начале `tools/generate_body_lines.py`. Раскладка подписей справа
разводится автоматически, чтобы блоки не накладывались друг на друга.
