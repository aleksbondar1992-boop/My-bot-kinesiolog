# Управление компьютером с телефона

Настройка Claude Code **Remote Control** для Windows: включил компьютер —
и с телефона видишь все свои проекты-ассистенты («Персональный астролог»,
«Кинезиолог», «Создание ботов» и т.д.), пишешь им задания, читаешь ответы.

---

## Сначала главное — как это вообще работает

Claude запускается **на твоём компьютере**. Телефон — это просто окно в него.

Отсюда следует самое важное ограничение:

> ⚠️ **Компьютер должен быть включён и не спать.**
> Выключенный или спящий компьютер с телефона не поднимется —
> это физическое ограничение, а не вопрос настройки.

Если нужно работать **с выключенным компьютером** — это другой инструмент,
Claude Code в облаке (claude.ai/code). Он не видит твои локальные папки,
работает только с репозиториями на GitHub. Про это в конце файла.

---

## Что нужно сделать один раз

### Шаг 1. Установить Claude Code на компьютер

Если ещё не установлен — открой PowerShell и выполни:

```powershell
npm install -g @anthropic-ai/claude-code
```

(Нужен Node.js 18 или новее — качается с nodejs.org.)

### Шаг 2. Войти в аккаунт

```powershell
claude
```

Внутри набери `/login` и войди через claude.ai.

> Нужна подписка **Pro или Max**. По API-ключу Remote Control не работает —
> если в системе прописана переменная `ANTHROPIC_API_KEY`, её нужно убрать.

### Шаг 3. Один раз открыть каждую папку проекта

Это обязательный шаг, его часто пропускают. Для каждой папки:

```powershell
cd C:\Projects\astrolog
claude
```

При первом запуске Claude спросит, доверяешь ли ты этой папке — ответь «да».
Пока это не сделано, Remote Control из этой папки не стартует.
Потом можно выйти командой `/exit`.

Повтори для всех папок: астролог, кинезиолог, боты и так далее.

### Шаг 4. Проверить список проектов

Файл **`rc-projects.txt`** уже заполнен твоими папками — правя́ть скорее
всего ничего не нужно. Формат такой:

```
Название сессии|Путь к папке
```

```
Кинезиолог|%USERPROFILE%\Documents\My-bot-kinesiolog
Создание ботов|%USERPROFILE%\Documents\expert-bot-skeleton
Второй мозг|%USERPROFILE%\Documents\Второй мозг
```

`%USERPROFILE%` подставляется автоматически — это твоя папка
`C:\Users\ТвоёИмя`. Вписывать своё имя вручную не нужно.

Название слева — то, что ты увидишь в приложении на телефоне.
Можно по-русски, проектов сколько угодно.

Если какой-то папки на компьютере не окажется, `start.bat` напишет
`folder not found` и покажет путь — тогда поправь строку. Узнать
настоящий путь: открой папку в Проводнике и кликни по адресной строке.

### Шаг 5. Установить автозапуск

Двойной клик по **`install.bat`**.

Скрипт зарегистрирует задачу в Планировщике Windows (права администратора
не нужны) и сразу запустит все проекты, чтобы можно было проверить.

Всё. Теперь при каждом включении компьютера, через 30 секунд после входа
в систему, все сессии поднимутся сами.

## Как пользоваться с телефона

1. Установи приложение **Claude** (App Store / Google Play).
2. Войди тем же аккаунтом, что и на компьютере.
3. Внизу выбери вкладку **Code**.
4. Увидишь список своих сессий: «Персональный астролог», «Кинезиолог»...
   У активных — иконка компьютера и зелёная точка.
5. Заходи в любую и пиши задания как обычно.

Первое подключение после включения компьютера может занять до минуты.

### Уведомления на телефон

Чтобы телефон сообщал, когда задача готова или нужен твой ответ —
на компьютере запусти `claude`, набери `/config` и включи:

- **Push when Claude decides** — когда закончил долгую задачу
- **Push when actions required** — когда нужно разрешение или ответ

## Чтобы компьютер не засыпал

Пока тебя нет, компьютер не должен уходить в спящий режим.

**Параметры → Система → Питание → Спящий режим → Никогда.**

Или сразу через PowerShell:

```powershell
powercfg /change standby-timeout-ac 0
powercfg /change hibernate-timeout-ac 0
```

То же самое можно сделать при установке:

```powershell
powershell -ExecutionPolicy Bypass -File Install-Autostart.ps1 -PreventSleep
```

Экран при этом гаснуть может — это не мешает, главное чтобы система не спала.

## Файлы в этой папке

| Файл | Зачем |
|---|---|
| `rc-projects.txt` | Список твоих проектов — единственное, что нужно править |
| `install.bat` | Установить автозапуск (запускается один раз) |
| `start.bat` | Запустить всё прямо сейчас, вручную |
| `stop.bat` | Остановить всё |
| `uninstall.bat` | Убрать автозапуск |
| `logs.bat` | Открыть папку с логами — смотреть, если что-то не работает |

Остальные файлы (`*.ps1`) — рабочие скрипты, трогать не нужно.

### Если поменял список проектов

- **Добавил проект или изменил путь** — просто запусти `start.bat` ещё раз.
  Уже работающие проекты он не трогает, новый поднимет, а если у проекта
  сменилась папка — перезапустит его на новую.
- **Удалил проект из списка** — сначала `stop.bat`, потом `start.bat`.
  Иначе удалённый проект останется висеть до перезагрузки.

Не забудь для новой папки сделать Шаг 3 (один раз запустить в ней `claude`
и подтвердить доверие).

## Если что-то не работает

**Первым делом открой `logs.bat`** — там по файлу на каждый проект,
в них видно, что именно пошло не так.

Частые случаи:

**«Claude Code is not installed, or not on PATH»**
Claude не установлен, либо установлен только что — закрой все окна терминала
и открой заново, чтобы обновился PATH.

**«folder not found»**
Неправильный путь в `rc-projects.txt`. Проверь, скопируй путь заново из Проводника.

**«Remote Control requires a claude.ai subscription»**
Не выполнен вход, либо в системе прописан `ANTHROPIC_API_KEY`.
Убери переменную и выполни `claude auth login`.

**«Remote Control requires a full-scope login token»**
Вход сделан долгоживущим токеном. Нужно `claude auth login` заново.

**«Remote Control is not yet enabled for your account»**
Выполни `claude auth logout`, затем `claude auth login`.
Диагностика: `claude doctor`.

**Сессия не появляется в телефоне**
Проверь, что компьютер не спит и есть интернет. Открой `logs.bat` —
если там `server exited`, watchdog перезапустит сам через несколько секунд.

**Проект пропал из списка через несколько часов**
Так бывает, если сеть пропадала дольше 10 минут — сессия закрывается.
Watchdog поднимет новую автоматически, просто подожди минуту.

## Запасной вариант: работа с выключенным компьютером

Если компьютер выключен, Remote Control не поможет. Тогда — **Claude Code
в облаке**: заходишь на [claude.ai/code](https://claude.ai/code) или в
приложение, вкладка Code, и запускаешь задачу в облаке Anthropic.

Разница:

|  | Remote Control | Claude Code в облаке |
|---|---|---|
| Компьютер нужен включённым | да | нет |
| Видит локальные папки | да | нет, только GitHub |
| Твои настройки и MCP-серверы | да | нет |

Практично так: локальные проекты — через Remote Control, а то, что лежит
на GitHub (например, бот кинезиолога) — можно править из облака в любой момент.
