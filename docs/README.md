# Документы

## Питание БГБКБС · ВЕГАН

Диета без сахара, без глютена, без молочки, без мяса, рыбы и яиц — веган-версия
протокола БГБКБС. 32 страницы, навигация по кликабельным ссылкам.

| Файл | Что это |
| --- | --- |
| `Pitanie_BGBKBS_VEGAN.pdf` | Готовый документ для выдачи клиенту |
| `pitanie-bgbkbs-vegan.html` | Исходник. Номера страниц — токенами `{{pN}}` |
| `build.py` | Сборка: проставляет номера и рендерит PDF |
| `build/index.html` | Собранный HTML (номера уже проставлены) |

### Как пересобрать

```bash
python3 docs/build.py
```

### Как редактировать

Правь только `pitanie-bgbkbs-vegan.html`.

Одна секция `<section class="page" id="pN">` = одна страница A4. Номера страниц
нигде не пишутся руками: в шапке секции и во всех ссылках стоят токены
`{{pN}}`, где `pN` — id секции-адресата. При добавлении, удалении или
перестановке секций `build.py` пересчитает все номера сам.

После правок проверь, что контент не выходит за границы страниц: в исходнике
есть служебный скрипт `<script id="measure">`, который считает переполнение.

```bash
CHROME=/opt/pw-browsers/chromium-1194/chrome-linux/chrome
$CHROME --headless --disable-gpu --no-sandbox --virtual-time-budget=6000 \
  --dump-dom file://$PWD/docs/pitanie-bgbkbs-vegan.html 2>/dev/null \
  | grep -o 'MEASURE_OUT">@@[^@]*@@' | sed 's/MEASURE_OUT">@@//;s/@@//' \
  | tr ' ' '\n' | awk -F: '{if($2>0) printf "OVERFLOW %s %dpx\n",$1,$2}'
```

Пустой вывод — все страницы помещаются. В PDF этот скрипт не попадает.
