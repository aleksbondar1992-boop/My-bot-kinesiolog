# Экспорт Telegram-канала на диск D

Скачивает **всё, кроме видео**, из вашего открытого канала и сразу раскладывает по папкам:

```
D:\Экспорт_канала\
├── 01_Сертификаты_и_документы\
├── 02_Отзывы\
├── 03_Результаты\
├── 04_Обычные_фото\
├── 05_Прочее\              (аудио, голосовые, посты без картинок)
├── КАТАЛОГ.html            ← открыть двойным кликом: все файлы с превью и поиском
├── КАТАЛОГ.csv             ← та же таблица для Excel
└── ВСЕ_ТЕКСТЫ_ПОСТОВ.md    ← подписи ко всем постам
```

Рядом с каждым файлом лежит `.txt` с текстом поста — контекст не теряется.
Видео, кружки и GIF не скачиваются (они и есть видео).

---

## Способ 1 — автоматический (рекомендую)

Скрипт сам заходит в Telegram, качает и раскладывает.

**Шаг 1. Python.** Если не установлен — https://python.org/downloads,
при установке обязательно галочка **«Add python.exe to PATH»**.

**Шаг 2. Получить api_id и api_hash** (бесплатно, 2 минуты, один раз):
1. откройте https://my.telegram.org → **API development tools**;
2. войдите по своему номеру телефона;
3. создайте приложение — название любое, например `export`;
4. скопируйте **App api_id** и **App api_hash**.

**Шаг 3. Запуск.** Двойной клик по **`1_СКАЧАТЬ_КАНАЛ.bat`**.
Скрипт спросит по очереди:
- `api_id` и `api_hash` (из шага 2 — запомнит, больше спрашивать не будет);
- номер телефона и код подтверждения из Telegram (обычный вход в аккаунт);
- ссылку на канал — можно `@имя_канала` или `https://t.me/имя_канала`.

Дальше он всё сделает сам. По умолчанию сохраняет в `D:\Экспорт_канала`.

> Ключи и вход хранятся **только на вашем компьютере** — в `config.local.json`
> и файле сессии. В репозиторий они не попадают.

### Полезные варианты запуска

Откройте папку в командной строке (в адресной строке проводника напишите `cmd`):

```bat
:: посмотреть раскладку, ничего не качая
1_СКАЧАТЬ_КАНАЛ.bat --dry-run

:: сохранить в другое место
1_СКАЧАТЬ_КАНАЛ.bat --out "D:\Материалы канала"

:: попробовать на последних 50 постах
1_СКАЧАТЬ_КАНАЛ.bat --limit 50

:: указать канал сразу
1_СКАЧАТЬ_КАНАЛ.bat --channel @my_channel
```

Экспорт можно прервать (Ctrl+C) и запустить снова — продолжит с места остановки,
скачанное заново качать не будет.

## Способ 2 — без api-ключей

Если возиться с `my.telegram.org` не хочется:

1. в **Telegram Desktop** откройте канал → меню «⋮» → **Экспорт истории чата**;
2. отметьте **Фотографии** и **Файлы**, снимите галочки с **Видео** и **Видеосообщений**;
3. формат — **JSON** (не HTML!), путь — любой, например `D:\ChatExport`;
4. дождитесь конца выгрузки;
5. в командной строке в этой папке:

```bat
.venv\Scripts\activate
python sort_desktop_export.py --src "D:\ChatExport" --out "D:\Экспорт_канала"
```

Скрипт разберёт выгрузку и разложит по тем же папкам. Файлы копируются,
исходная выгрузка остаётся целой (`--move` — если хотите перенести).

## Как работает раскладка

Категория выбирается по **словам в тексте поста** (файл `categories.json`):

| Папка | Слова-маркеры |
|---|---|
| 01_Сертификаты_и_документы | сертификат, диплом, удостоверение, лицензия, квалификация… |
| 02_Отзывы | отзыв, благодарность, рекомендую, клиент пишет, обратная связь… |
| 03_Результаты | результат, до и после, боль ушла, за 1 приём, динамика, кейс… |
| 04_Обычные_фото | фото, где ничего из перечисленного не нашлось |
| 05_Прочее | аудио, голосовые, посты без картинок |

Слова ищутся **по корню и без учёта регистра**: «сертификат» поймает
«Сертификаты», «сертификатом». Буквы `е` и `ё` считаются одинаковыми.
PDF и Word-файлы без ключевых слов уходят в документы, картинки — в обычные фото.

### Если что-то легло не туда

1. откройте `categories.json` в «Блокноте» и добавьте свои слова в нужный список
   (`keywords` — сильные, `weak_keywords` — вспомогательные);
2. двойной клик по **`2_ПЕРЕСОРТИРОВАТЬ.bat`** — файлы переедут по новым правилам
   **без повторного скачивания**, каталог пересоберётся.

Колонка **«почему»** в `КАТАЛОГ.csv` показывает, какое слово сработало —
по ней удобно понять, что подправить.

Часть постов всё равно придётся разложить руками: понять по тексту, что на фото
результат, а не просто снимок с приёма, автоматика может не всегда. Файлы обычные,
их можно свободно перетаскивать между папками мышкой — на работу скриптов это не влияет
(после ручного переноса не запускайте пересортировку, иначе она вернёт файлы обратно
по словам из текста).

## Частые вопросы

**Канал закрытый / это чужой канал.** Способ 1 работает с любым каналом, который
открыт в вашем аккаунте. Экспортируйте только то, на что у вас есть права.

**«Telegram просит подождать N секунд».** Нормально: защита от частых запросов.
Скрипт сам ждёт и продолжает — не закрывайте окно.

**Ошибка на отдельных файлах.** Такие посты записываются в `ошибки.log`,
остальное продолжает качаться. Повторный запуск попробует их снова.

**Сколько занимает.** Зависит от объёма: тысяча фото — примерно 10–25 минут.

**Можно ли на диск C или флешку.** Да: `--out "E:\Папка"`.
