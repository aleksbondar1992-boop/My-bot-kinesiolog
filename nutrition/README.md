# Питание БГБКБС — без сахара, без глютена, без молочки

Материалы для клиента: меню на 7 дней, схема дня по часам, замены и список покупок.

## Готовые файлы

| Файл | Что внутри |
|---|---|
| `pitanie-bgbkbs-menu.pdf` | 7 страниц: правило дня, схема дня по часам, меню на 7 дней, замены, покупки, шпаргалка «нельзя/можно», клетчатка, общие рекомендации |
| `pitanie-bgbkbs-menu.xlsx` | 8 листов: Как читать · Схема дня · Меню 7 дней · Замены · Покупки · Можно-Нельзя · Клетчатка · Рекомендации |

В Excel единственная ячейка для заполнения — жёлтая (вес) на листе «Как читать»:
норма воды считается формулой `= вес × 30 / 1000`. Рядом лежит готовая справка
по весам от 45 до 100 кг, чтобы цифра была видна и без пересчёта.

## Источник

Всё содержание собрано из рабочей базы **«Нутрициология · Анатомия Здоровья»**
(`Нутрициология_база.pdf`) — разделы: диета БГБКБС, детокс/очищение,
продукты для снижения отёков, вздутый живот.

Дополнительные условия, заданные под конкретного клиента:

- завтрак белково-жировой; обед — белок, жир и углеводы; ужин — только белок и жир;
- клетчатка в каждый приём, отварная или ошпаренная;
- сорбент **псиллиум** между приёмами пищи: за 2 ч до еды или через 2 ч после;
- после завтрака — масло пшеничных зародышей (витамин Е), витамин А из еды, омега-3, цинк;
- витамин С — между приёмами пищи;
- **травки** — после каждого приёма пищи;
- исключены курица, пшеница, мука белая 1 сорта, ржаная мука;
- рацион собирается из «Пятёрочки», «Перекрёстка» и «ВкусВилла».

Дозировки БАДов (омега-3 1600 мг, витамин С 1000 мг, цинк 25 мг) взяты из базы.
D3, магний, куркумин, йод и сироп солодки в основную схему не включены — они
вынесены отдельной таблицей «Дополнительно из базы, по согласованию».

## Пересборка

```bash
pip install openpyxl reportlab
cd nutrition
python3 build_xlsx.py    # -> pitanie-bgbkbs-menu.xlsx
python3 build_pdf.py     # -> pitanie-bgbkbs-menu.pdf
```

Весь текст лежит в одном месте — `plan_data.py`. Правится он, затем оба скрипта
пересобираются, и PDF с Excel остаются согласованными между собой.

PDF собирается шрифтами DejaVu Sans (кириллица), путь
`/usr/share/fonts/truetype/dejavu`.
