# Подключение локальной модели Hermes к боту

Бот умеет работать в двух режимах:

- **Облако (Gemini)** — режим по умолчанию, ничего настраивать не нужно.
- **Локальная модель (Hermes через Ollama)** — включается, если задать переменную `LOCAL_AI_URL`.

## Шаг 1. Запустить Hermes на ПК (Windows)

Ollama уже установлен. В командной строке (`Win` → набери `cmd` → Enter):

```
ollama run hermes3:8b
```

Первый раз модель скачается (~4–5 ГБ), потом запускается мгновенно.
Можно проверить, что сервер отвечает, открыв в браузере: http://localhost:11434

## Шаг 2. Указать боту адрес модели

Бот выбирает модель по переменным окружения:

| Переменная        | Значение для Ollama                              |
|-------------------|--------------------------------------------------|
| `LOCAL_AI_URL`    | `http://localhost:11434/v1/chat/completions`     |
| `LOCAL_AI_MODEL`  | `hermes3:8b` (по умолчанию)                       |

Если `LOCAL_AI_URL` **не задан** — бот работает на Gemini, как раньше.

### Если бот запускается на том же ПК, где Ollama
Достаточно `localhost` — никакой «айпи» не нужен.

### Если бот живёт на хостинге (в облаке)
`localhost` хостингу недоступен — ему нужно как-то достучаться до твоего домашнего ПК.
Самый безопасный способ — туннель (не открывать домашний IP наружу):

1. Установить ngrok: https://ngrok.com/download
2. Запустить туннель к Ollama:
   ```
   ngrok http 11434
   ```
3. ngrok выдаст адрес вида `https://xxxx.ngrok-free.app`.
   Тогда на хостинге укажи:
   ```
   LOCAL_AI_URL=https://xxxx.ngrok-free.app/v1/chat/completions
   ```

> ⚠️ Минус туннеля: пока ПК выключен или ngrok закрыт — бот не сможет отвечать.
> Поэтому для постоянной работы 24/7 локальная модель на домашнем ПК подходит плохо.
> Для «поиграться и посмотреть» — отлично.
