# Карусель «Здоровье × Эзотерика»

Готовые карточки для Instagram-карусели. 7 штук, формат 1080×1350 (4:5 — самый
крупный в ленте). Заливать по порядку `card-01` → `card-07`.

Идея: не спорить с эзотерикой, а переводить её на язык тела. Каждая карточка —
одна параллель: слева то, как это называет эзотерика, справа — что за этим стоит
анатомически. Позиционирование мягкое, экспертное, без обесценивания аудитории.

## Как пересобрать

Правки текста — в `src/content.py`, вёрстка и стиль — в `src/build.py`.

```bash
cd social-cards/src && python3 build.py
```

Рендер идёт через headless Chromium в `png/*.png`. Шрифты (Manrope +
Playfair Display с кириллицей, обе лицензии SIL OFL) лежат рядом в
`src/fonts/woff` и вшиваются в HTML base64-ом — сеть для сборки не нужна.
Путь к Chromium задан в `build.py` константой `CHROME`.
